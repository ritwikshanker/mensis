# Mensis

A cycle tracker that keeps your data on your phone.

Mensis is a private menstrual cycle tracker for Android: no account, no analytics, no ads. Everything you
log stays on the phone in an encrypted database; an optional backup to your own Google Drive is
encrypted on the phone with a password only you know. The code is open source under the MIT licence.

- [Privacy policy](privacy/)
- [Source code](https://github.com/ritwikshanker/mensis)
- [Releases](https://github.com/ritwikshanker/mensis/releases)
- [Export file format](export-format.html)

Predictions are statistics about your own history. Mensis is not a medical device and is not a method of
contraception.
